[h1]A Brave New World DLL mod (Windows only) with bug fixes, AI improvements, API extensions, and quality-of-life features.[/h1]

Gaia's Core Mod replaces the Brave New World game core with a deterministic, multiplayer-safe DLL. It is not a content pack; it provides the shared AI, database, API, bug-fix, quality-of-life, and interface framework used by Gaia's mods and modules.

[b]Gameplay content now lives in the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2309504487]Sapiens[/url] mod.[/b] The Core supplies the framework it runs on.

[quote][h2]Configure it yourself: CORE_OPTIONS.sql and USER_SETTINGS.sql[/h2]
Two plain-text files sit in the mod's own folder and control everything the Core does. Open either one in any text editor, change what you like, save, and start a new game.

[b]CORE_OPTIONS.sql[/b] is the on/off list for every Core feature, each with a one-line explanation of what it does. By default only [b]AI improvements[/b], [b]bug fixes[/b], and selected [b]quality-of-life fixes[/b] are enabled. Set them all to 0 to restore [b]exact vanilla Brave New World[/b] behavior, engine and rules alike.

[b]USER_SETTINGS.sql[/b] holds the numbers: animation speed, barbarian behavior, AI gold reserves, etc. Every line explains what it changes and notes its original default, so you can always put it back.

A Workshop update replaces both files, so keep a copy of your edits if you change them.
[/quote]

[quote][h3]COMPATIBILITY[/h3]
Requires the [b]Brave New World[/b] expansion. Because it includes its own game-core DLL, Gaia's Core Mod is [b]not compatible with other DLL mods[/b], including VMC, CP / Vox Populi, and LEKMOD.

Like every DLL mod, it works only on the [b]Windows version[/b] of the game. The Mac and Linux (Aspyr) ports cannot load custom DLL mods; on Linux, run the Windows build through Steam Play (Proton). Mods from [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3446329507]this collection[/url] whose names start with [b]+[/b] or [b]=[/b] do not need the DLL and still work on Mac and Linux.

On the interface side, the Core is fully compatible with [b]EUI[/b]. Alternatively, you can install [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2405220158]Gaia's Core UI[/url], a custom interface replacement for EUI that enables additional Core functions unavailable through the stock UI.
[/quote]
